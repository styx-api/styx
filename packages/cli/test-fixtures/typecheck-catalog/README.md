# Codegen typecheck catalog

A small curated catalog whose **generated code is type-checked in CI**. The
`codegen-typecheck` CI job (and `npm run typecheck:codegen` locally) generates
Python + TypeScript from this catalog and runs `mypy --strict` and
`tsc --noEmit` over the output via [`scripts/typecheck-codegen.mjs`](../../../../scripts/typecheck-codegen.mjs).

This complements the string-matching unit tests: those pin specific emitted
shapes, but only running the real type-checkers proves the generated code
actually type-checks. It catches whole classes of bugs the unit tests miss -
declaration ordering / forward references, optional-omit `NotRequired`,
union-output `never` collapses, indexability.

## Tools

| Tool                  | Shape it guards                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `dwi2response`        | Vendored mrtrix descriptor: a discriminated union of sub-command structs where several variants share a nested literal-union field (`wm_algo`). This nested-union-inside-union ordering regressed the Python backend (NameError at import + ~200 mypy errors) and is fixed by the type-declaration topological sort.                                                                                                                                                                                                                                                                 |
| `shapes`              | Scalars (int/float/str/file), an optional boolean flag, a required list (`list[float]`), an optional repeatable list, optional-without-default fields (the `typing.NotRequired` path), and an output file.                                                                                                                                                                                                                                                                                                                                                                           |
| `DenoiseImage`        | Vendored ANTs descriptor: a union-typed output (variants declare different output-files), so the resolved Outputs type is a union across arms - the shape that previously collapsed to `never`.                                                                                                                                                                                                                                                                                                                                                                                      |
| `antsApplyTransforms` | Vendored ANTs descriptor: a mixed (struct + bare-literal) union (`interpolation`); cargs branch on runtime shape (`isinstance` dict) because literal arms have no `@type`.                                                                                                                                                                                                                                                                                                                                                                                                           |
| `mutate`              | Hand-written: a mutable File input, staged as a writable copy (`input_file(mutable=True)`) and also surfaced as an `OutputPathType` field via `mutable_copy` - exercises both the cargs and Outputs paths of the mutable primitive.                                                                                                                                                                                                                                                                                                                                                  |
| `borderMerge`         | Vendored Connectome Workbench descriptor (the only `workbench` source-format fixture): a repeatable option carrying a struct (`list[struct]`), deeply nested options/flags (`-border` -> `-select` -> `-up-to` -> `-reverse`), and a positional output referenced by name - the workbench frontend's happy path.                                                                                                                                                                                                                                                                     |
| `dupOutputs`          | Hand-written: two ungated `output-files` sharing an id (the afni `v_3d_detrend` shape). The required-single Outputs local is declared once and reassigned by later contributors; a second annotated declaration of the same local was a mypy --strict `no-redef`.                                                                                                                                                                                                                                                                                                                    |
| `dupVariant`          | Hand-written: a repeatable discriminated union with two byte-identical sub-commands sharing an id (the c3d `c2d`/`c3d`/`c4d` `-orient` shape). The Boutiques frontend dodges the duplicate id (`orient` -> `orient_2`) so each arm keeps a unique `@type`; without it the second arm would be an unreachable dead branch (a mypy --strict `comparison-overlap`).                                                                                                                                                                                                                     |
| `variousTypes`        | Hand-written: a union of two _distinct_ sub-commands (`VariousString`/`VariousFile`) that each collapse onto a single inner field both named `obj` (the mrtrix `mrcalc`/`mrconvert` shape). The `@type` comes from the sub-command id (via `variantTag`, preserved through the collapse) so both variants stay distinct and reachable; deriving it from the shared inner field name made the File variant unreachable, and now trips the backend's duplicate-`@type` guard.                                                                                                          |
| `mrtrixDemo`          | Hand-written, the only `mrtrix` (native C++ dump) source-format fixture: exercises the frontend's output-file args, the `various` `str\|file` union, a `choice` enum (`algorithm`), a comma-separated `int seq`, a repeatable multi-arg option (`-config`), and a positional/option id collision (`output`) that the frontend disambiguates (`output` -> `output_2`) - shapes specific to the MRtrix dump frontend.                                                                                                                                                                  |
| `mixedOutput`         | Hand-written: a mixed (bare-literal + struct) union (`quality_check = Literal[0] \| QcOn`) whose struct arm owns an output-file (the ants `antsIntroduction.sh` `n4_correction` / `quality_check` shape). The output is gated on the struct variant, so the `_outputs` emitter renders a `@type` check on the union value - a non-indexable type error (and a runtime KeyError on the literal arm) unless a shape guard (`isinstance` dict / `typeof === object`) narrows off the bare-literal arm first. The cargs builder and validator already guarded; the outputs gate did not. |

## Adding a fixture

1. Add an app directory under `suite/1.0/<name>/` with an `app.json`
   (`source.path` pointing at a colocated descriptor) and the descriptor file.
2. List `<name>` in `suite/1.0/version.json`'s `apps` array.
3. Run `npm run typecheck:codegen` and confirm it stays green.

Prefer the smallest descriptor that exercises a distinct codegen path; vendor a
real descriptor when a shape is hard to hand-write (as with `dwi2response`).
